**World Builder Studios (WBS)** makes **world builders** — products where humans and agents **inhabit** a shared place (VEN / instance / room / wire), not only file cards or industrial paper.

We are not DATBOX Studio (datmats in bags).  
We are not Charlie’s Toys (personal objects).  
We are not Big Box Company (documentation industrial).  
We build **stages you walk into**. Materials from DATBOX may arrive later as importable VEN / lore furniture — stack, don’t merge.
