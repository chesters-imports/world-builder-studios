# Checkout

A slot is taken in the **facts**, not in the pretty.

A seat in a text room is occupied the same way a chair is occupied after Viz draws a body in it. Vox/Viz dress the fact. They do not own it.

Same machine as:

- exclusive checkout for a singular character (one Mira)
- multi-instance things with a cap (drinks, chairs, a tavern’s room)
- a quest lock (this role / this object is not free)

Capacity is ontology. You cannot pull a ven out of its container unless a dynamic allows the pull.

World spawn leans on this: “place near vens with `prop:canDwell`” only works if those dwell slots exist and are not already full.
